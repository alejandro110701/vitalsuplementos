## The 4-Step Process

**Inline Format (Catalog, Product, Checkout):**
```
pedido → confirmas por WhatsApp → foto de lote y caducidad de tu unidad → pagas al courier
```

**Numbered Format (Homepage, Checkout):**
1. pedido / Confirmas los productos y las cantidades aquí
2. confirmas por WhatsApp / Capturas la dirección de entrega en la tienda
3. foto de lote y caducidad de tu unidad / Eliges pago contra entrega o tarjeta y confirmas
4. pagas al courier / Te llega el correo con tu número de pedido

## Standard Copy (All Pages)
